# Seatbelt Labs

**Tools for good. Human agency.**

We're an independent software studio building tools to help people understand, guide, and trust the technology they use.

[seatbeltlabs.com](https://seatbeltlabs.com) · [Labs](https://seatbeltlabs.com/labs/) · [LinkedIn](https://www.linkedin.com/company/seatbeltlabs/)

## Projects

| Project | What it is | Status |
| --- | --- | --- |
| [Seatbelt](https://seatbeltlabs.com/seatbelt/) | A security check for the apps you build with coding agents. Read the project, find the risks, and get a report you can act on. | Available |
| [Looptender](https://seatbeltlabs.com/looptender/) | A supervisor for coding agents. Wake idle sessions, handle structured failures with bounded retries, and keep track of the work. | Early release |
| [TalkQTE](https://seatbeltlabs.com/talkqte/) | An early meeting companion exploring how a quiet, timely cue could help you stay grounded in the conversation. | Prototype |
| [Traceweave](https://seatbeltlabs.com/traceweave/) | An experimental open specification for embedded content marks, fingerprints, and verifiable provenance records. | Experimental spec |

Different projects. A shared point of view.
